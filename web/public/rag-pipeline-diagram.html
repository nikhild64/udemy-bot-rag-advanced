🌐
Client

1. Web Frontend & Auth

Next.js UI handles secure authentication, workspace state, file uploads, and streaming AI responses.

🛡️
Security

2. Gateway & Guardrails

Fastify API validates requests with input/output guardrails (XSS, PII, prompt injection, and output size control).

📥
Ingestion

3. Multimodal Ingestion

Parses PDFs, DOCX notes, web pages, and YouTube video/playlist transcripts into structured text nodes.

✂️
Processing

4. Chunking & Embeddings

Divides text into 500-1000 token semantic chunks preserving section headers, and generates dense vector embeddings.

💾
Storage

5. Database & Vector Memory

PostgreSQL manages user metadata and source records, while Qdrant stores high-speed vector embeddings.

🔍
Retrieval

6. Hybrid Search & Reranker

Combines vector similarity and keyword search, re-ranking candidate excerpts via CRAG evaluation.

✨
Synthesis

7. Grounded Answer Stream

Assembles system prompts, streams LLM response tokens, and attaches footnote citations with exact source quotes.
